# Windows reference

This folder preserves the C# / C++ Windows source and Stream Deck manifest/assets supplied in the Mac handoff. It was used to compare command mapping and timing with the Mac port.

The current working Windows installer is on another computer. Its version and full build contents have not been verified, so this repository does not yet publish a Windows release or claim that these reference sources reproduce that installer.

Windows release packages will use their own version and platform-specific tag after the current installer is identified.
